PySide6 / Qt for Python — third-party redistribution notice
==========================================================

The WinPodX Thin AppImage bundles the PySide6 (Qt for Python) runtime so
the Qt6 GUI works without a system Qt install. This directory ships the
license texts that PySide6's own wheels do not carry (verified: neither
the dist-info nor the PySide6/ tree contains them), to satisfy the
redistribution obligation. The exact versions bundled are recorded at
build time in PROVENANCE.json / SOURCE-OFFER.txt (next to the AppImage
and at usr/share/doc/winpodx/ inside it) — including the ACTUAL Qt
version, read from the shipped libQt6Core.so.6 bytes, not assumed from
the wheel version.

    https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-<VERSION>-src/pyside-setup-everywhere-src-<VERSION>.tar.xz

Replacing / relinking (LGPL): the AppImage is a SquashFS you can unpack
and re-pack. Run `./winpodx-x86_64.AppImage --appimage-extract` (or set
APPIMAGE_EXTRACT_AND_RUN=1 to run unpacked), replace
`squashfs-root/opt/python/lib/python3.11/site-packages/PySide6/Qt/lib/libQt6*.so*`
or `PySide6/*.abi3.so` with your own build of the corresponding source
    above, then run from `squashfs-root/AppRun` or re-pack with appimagetool
(pass `--runtime-file` with the pinned Type 2 runtime listed in
SOURCE-OFFER.txt). Extractability alone is not claimed to satisfy the
LGPL. The release also delivers winpodx-appimage-sources.tar.gz beside the
binary with equivalent network access: mirrored source bytes, patches,
notices and build inputs. SHA256SUMS binds that archive to the AppImage;
pip's report records resolved wheel hashes, not a pre-install hash lock.
These are engineering delivery records, not a complete legal assessment.
