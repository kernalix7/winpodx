rdprrap 0.3.0 — supplemental compiled-dependency notices (WinPodX legal-audit L1)
====================================================================================

Purpose
-------
This is a WinPodX-owned supplemental attribution file that closes the content
defect recorded as finding L1 in the WinPodX 0.12.0 pre-publication license
audit (.rtrt/tmp/release-0.12.0/legal-audit.md). The third-party notice
generated inside the bundled rdprrap ZIP attributes a single MIT block to 25
crate/version entries but reproduces only the placeholder text
"Copyright (c) <year> <copyright holders>". That placeholder does not name a
rights holder and cannot satisfy the retention condition of the MIT grant.
This file supplies the original copyright notice and the full, verbatim MIT
license text for the 17 external crates in that block, together with the
provenance of each text.

  Version pin:               config/oem/rdprrap_version.txt
                             (version=0.3.0, filename and SHA-256 match above)

----------------------------

  entries: 8 rdprrap-owned workspace crates plus the 17 external crates
  reproduced below.)

Scope and non-claims
--------------------
  - The 8 rdprrap-owned crates (listed below) are MIT-licensed under the
    ZIP's own top-level LICENSE (Copyright (c) 2026 Kim DaeHyun); that text
    ships inside the ZIP and is not duplicated here.
  - This file does not independently prove the compiled binary dependency
    graph. The graph is declared by the ZIP's generated manifest named above;
    this file reproduces the licensing data for the external entries in it.
  - Where a crate is offered under a choice ("MIT OR Apache-2.0"), the MIT
    alternative is reproduced here as a valid, complete grant.
  - The ZIP itself, its version pin, and the upstream rdprrap release were not
    modified, rebuilt, or re-pinned by producing this file.
